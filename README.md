# 🌱 EcoGuard Agent – AI for Sustainable Crop Health

EcoGuard Agent is a multi-agent AI system designed to assist farmers in early-stage plant disease detection, climate risk interpretation, and sustainable treatment recommendation.

Built as part of the **Agents Intensive Capstone Project**, EcoGuard demonstrates how agent-based AI systems can address real-world sustainability challenges in agriculture.

---

## 🚜 Problem Statement

Farmers often struggle to identify plant diseases early and understand how climate conditions affect disease spread. Delayed diagnosis and misuse of chemical pesticides lead to crop loss and environmental harm.

EcoGuard addresses this gap by combining vision-based disease detection with climate-aware reasoning and eco-friendly recommendations.

---

## 🧠 Solution Overview

EcoGuard uses a **sequential multi-agent architecture**:

1. Vision Disease Agent (Gemini Vision)
2. Climate Risk Agent (Rule-based)
3. Sustainability Recommendation Agent (Gemini)
4. Memory Agent
5. Orchestration Pipeline

Each agent performs a specialized role and passes structured outputs to the next.

## ⚙️ Agents Description

### Vision Disease Agent
- Analyzes plant leaf images using Gemini Vision
- Outputs disease status, name, confidence, and visible symptoms

### Climate Risk Agent
- Evaluates humidity and temperature effects on disease spread

### Sustainability Recommendation Agent
- Generates eco-friendly and farmer-friendly treatment guidance

### Memory Agent
- Stores recent analyses for session continuity
